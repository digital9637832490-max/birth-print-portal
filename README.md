3. State/UT management — all 36, add/edit/delete, active/inactive

10. Generated PDF history — preview/delete/clear
11. Admin settings — name, logo text, defaults, watermark, footer
12. Free GitHub Pages deployment guidance

## Run locally
Open `index.html` in a browser. For best results use a simple static server or GitHub Pages.

## GitHub Pages
Upload the contents of this folder to the repository root, then enable **Settings → Pages → Deploy from branch**. No backend is required for this demo build.

## Storage
The demo uses browser `localStorage` for states, languages, templates, fields, settings, and history. Login session uses `sessionStorage`.

## Safety / authenticity
Generated PDFs are clearly marked as DEMO/SAMPLE and NOT AN OFFICIAL GOVERNMENT DOCUMENT. Do not use the project to represent a document as an authentic government-issued certificate.
