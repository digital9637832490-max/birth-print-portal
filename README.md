# Birth Print Portal

Educational Admin Dashboard + Demo PDF Generator.

## Included
- Single Admin Dashboard
- State and language selection
- Template management
- Form field management
- Live A4 preview
- Demo PDF generation
- Local PDF history
- Settings
- Responsive UI
- GitHub Pages compatible static deployment

## Run
Open `index.html` in a browser, or publish the repository with GitHub Pages.

## Important
This project is for learning/demo purposes. Generated PDFs are explicitly marked:
`DEMO • SAMPLE • NOT AN OFFICIAL GOVERNMENT DOCUMENT`

Do not use generated output as an official government certificate or record.

## Source reference
The Maharashtra layout was designed as an educational visual reference from the user-provided sample PDF. No government verification or issuance functionality is included.
